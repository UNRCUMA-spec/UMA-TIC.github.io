Sistema binario

Descubre cómo las computadoras representan la información con 0 y 1 y aprende a convertir entre decimal y binario.

1. Bits y bytes

Todo lo que hace una computadora (texto, imágenes, sonido y programas) se guarda y se procesa como combinaciones de dos valores: 0 y 1.

Bit

0 o 1

Cada dígito del sistema binario. Es la unidad mínima de información.

Byte

8 bits

Permite 256 combinaciones, del 0 al 255 (28 = 256).

2. El valor de cada posición

El sistema decimal usa diez dígitos y cada posición vale una potencia de 10. El binario usa solo dos dígitos y cada posición vale una potencia de 2: de derecha a izquierda, cada una vale el doble de la anterior.

Pruébalo: toca los bits para encenderlos (1) o apagarlos (0) y mira qué número decimal forman.

Ejemplo: el número 13 es 1101, porque 8 + 4 + 0 + 1 = 13.

3. De decimal a binario

Se divide el número entre 2, se anota el residuo y se repite con el cociente hasta llegar a 0. Los residuos, leídos de abajo hacia arriba, forman el número binario.

Ejemplo con 13:

  • 13 ÷ 2 = 6residuo 1
  • 6 ÷ 2 = 3residuo 0
  • 3 ÷ 2 = 1residuo 1
  • 1 ÷ 2 = 0residuo 1

4. De binario a decimal

Se suma el valor de las posiciones que tienen 1. Las posiciones con 0 no aportan nada.

1101 = 1×8 + 1×4 + 0×2 + 1×1 = 8 + 4 + 0 + 1 = 13

Los ceros a la izquierda no cambian el valor: 1101 y 00001101 son el mismo número.
