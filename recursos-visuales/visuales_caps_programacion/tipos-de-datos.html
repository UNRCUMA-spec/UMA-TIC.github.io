Las variables y los tipos de datos

Aprende cómo una variable guarda información y descubre cuatro tipos de datos básicos.

1. Imagina una caja

Una variable es como una caja con nombre. En ella guardamos un dato para utilizarlo después en un programa.

edad = 20

¿Cómo leerlo? La variable se llama edad y guarda el número 20.
