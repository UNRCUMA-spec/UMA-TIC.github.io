Condicionales: if / else

Descubre cómo un programa toma decisiones: evalúa una condición y elige qué camino seguir.

1. ¿Qué es un condicional?

Cuando una aplicación te pide la contraseña, revisa si es correcta; si lo es, te deja entrar y, si no, te muestra un error. Esa decisión se programa con un condicional: un bloque de código que se ejecuta solo si una condición es verdadera.

if

«Si» la condición se cumple, ejecuta este bloque.

elif

«Si no, pero si…»: prueba otra condición. Es opcional y puede repetirse.

else

«Si no»: se ejecuta cuando ninguna condición anterior se cumplió.

La condición es una expresión que da como resultado True (verdadero) o False (falso), el tipo de dato booleano. Después de if, elif y else se escriben dos puntos (:) y el bloque va sangrado (con sangría).

2. Pruébalo: ¿puede votar?

Cambia la edad y mira qué línea del programa se ejecuta.

edad = 17if edad >= 18:    print("Puedes votar")else:    print("Aún no puedes votar")
Condición edad >= 1817 >= 18 → False
Salida del programaAún no puedes votar

Escribe un número entero entre 0 y 120.

3. Operadores de comparación

Para armar una condición se comparan valores. Cada comparación da True o False.

OperadorSignificaEjemplo
==igual a5 == 5 → True
!=distinto de5 != 3 → True
>mayor que4 > 7 → False
<menor que4 < 7 → True
>=mayor o igual que18 >= 18 → True
<=menor o igual que9 <= 6 → False

Ojo: un solo signo = guarda un valor en una variable (edad = 18); dos signos == comparan.

4. Más de dos caminos con elif

Con elif el programa puede elegir entre varias opciones. Python revisa las condiciones en orden y ejecuta solo la primera que se cumple.

calificacion = 7if calificacion >= 9:    print("Excelente")elif calificacion >= 6:    print("Aprobado")else:    print("Reprobado")
Salida del programaAprobado

Escribe un número entero entre 0 y 10.
