## 📌 Descripción del Proyecto
**UMA-TIC** es una plataforma web educativa diseñada e implementada como parte de los proyectos de innovación académica de la **Universidad Nacional Rosario Castellanos (UNRC)**. El sistema ofrece cápsulas de microaprendizaje dinámicas e interactivas orientadas a reforzar competencias clave en asignaturas de alta complejidad para los estudiantes de los primeros semestres.

---

## 🏛️ Estructura del Repositorio
El código se encuentra modularizado siguiendo buenas prácticas de desarrollo web para facilitar su mantenimiento y escalabilidad:

```text
├── index.html              # Estructura principal y vistas de la interfaz
├── styles.css              # Estilos personalizados y diseño responsivo
├── main.js                 # Lógica general, navegación SPA y filtros
├── README.md               # Documentación oficial del repositorio
└── capsulas
    ├── sociales.js         # Contenido y ejercicios del área de Ciencias Sociales
    ├── programacion.js     # Contenido y ejercicios del área de Programación
    └── matematicas.js      # Contenido y ejercicios del área de Matemáticas
